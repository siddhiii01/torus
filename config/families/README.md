# Form families (generated hints)

YAML files here are **auto-learned label layouts** (P4.7). They speed up and
stabilise field location but are **never required** for correctness.

| Status | Meaning |
|---|---|
| `observing` | Seen once; not used as a hint yet |
| `generated` | Seen enough times to auto-save; may be used as a hint |
| `reviewed` | Human approved |
| `rejected` | Human rejected; ignored |

Agents write `observing` / `generated` files. Humans change status to
`reviewed` or `rejected` and may edit label centres. Do not put real document
text or customer identifiers in these files.
